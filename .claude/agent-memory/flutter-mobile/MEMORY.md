## Important Gotchas
- Windows: `build_runner build` regenerates ALL managed generated files project-wide; with `core.autocrlf=true` this makes `git status` show hundreds of unrelated files as modified (pure LF/CRLF noise — verify with `git diff --ignore-all-space --stat`, then `git checkout --` them before staging). A large `git checkout --` batch can time out and leave a stale `.git/worktrees/<name>/index.lock` — safe to `rm` if no git process is actually running (check `tasklist`), it's scoped to that one worktree's index only. See [[msv32-f3-timeline-summary-error-state]]
- shimmer package NOT available — use AnimationController-based `_SkeletonBox` (ColorTween neutral[100]↔neutral[50], 1400ms repeat); pattern in `character_tab_screen.dart` + `bio_card.dart`
- `withOpacity()` deprecated in Flutter 3.27 — use `withValues(alpha: X)`
- `createdAt` on Freezed models is `DateTime?` (parsed by json_serializable) — do NOT wrap in `DateTime.parse()`
- `Future.catchError((_) => null)` fails on non-nullable return types — use try/catch blocks
- `MainNavCubit.selectTab(3)` navigates to Stats tab from main tab widgets
- `flutter_foreground_task` v8.x lacks `isSticky`/`foregroundServiceTypes` params — do NOT use them
- `CaptureFlowConfig.debrief()` is a factory (not const) — screen using it cannot be `const`
- WOW screen post-onboarding debrief: use `context.go(mainPage)` then `context.push(debrief)` so back lands on main page, not black screen
- Language selection dialog: `LanguageSelection.show(context)` (static method, not `LanguageSelectionDialog`)
- `ExpansionTile.minTileHeight` IS available in Flutter 3.27 — confirmed working
- `Spacer()` inside Column inside MsSilverScrollView causes layout issues — replace with `SizedBox(height: N)`
- Symptom archive/restore: `isVisible=false` = archived; cubit has `archiveSymptom`/`restoreSymptom` — NOT `toggleVisibility`/`togglePause`; Settings symptoms section is read-only, deletion only via Stats tab `SymptomManagementSheet` (two-tier: simple dialog <5 scores, type-to-confirm >=5 scores)
- `tutorial_coach_mark` package + Walkthrough system REMOVED (Mar 2026) — do not reference TutorialManager/WalkthroughCubit/etc.; `SettingsCubit.resetAllTutorials()` still exists (resets local prefs only, button removed from UI)
