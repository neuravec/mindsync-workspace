Non-obvious findings:
- **Layout-guard recipe** (`test/screens/first_conversation/first_conversation_intro_layout_test.dart`): load Figtree in `setUpAll` via `FontLoader` + `File('assets/fonts/...').readAsBytesSync()` and use `AppTheme.theme` for a realistic proportional-font run; use `ThemeData()` for the wide-test-glyph stress run (glyphs ~2x wider than a real font: only valid for "no overflow", never for "fits"). Insets via `tester.view.padding`/`viewPadding = FakeViewPadding(... * dpr)`. Overflow detection = `tester.takeException()` is null. Prove non-vacuous by mutating the layout back (all 13 cases failed).
- **Test bug to avoid**: after dragging a short body viewport to the end, items above the last one are legitimately off screen; check each with `scrollUntilVisible` instead of asserting them all in one scroll position.
- **Possible app-wide font mismatch (NOT device-verified, not fixed)**: pubspec declares the Figtree .ttf files under family `Lato`, but `AppTheme.theme` asks for `fontFamily: 'Figtree'` (and widgets hard-code 'Figtree'). Unregistered family falls back to the platform font, so devices likely render SF Pro/Roboto everywhere while marketing shots (which register 'Figtree' by hand) render Figtree. Reported to the lead; any fix is an app-wide visual change needing design sign-off.

Follow-up commit 6c70dd4 (brand review): focus-area labels interpolated mid-sentence were capitalized ("How Sleep has shown up this week", "How are Stress today?"). Helpers in `lib/utils/symptom_presets.dart`: `focusAreaMidSentence(label, languageCode)` (lowercase first letter; kept in German, for 2+ capitals/acronyms, and English weekday/month/"I" words), `placeholderOpensSentence(template)` (probe with a private-use char: reads the position from the localized template itself), `focusAreaInTemplate(context, template, label)` (capitalizes when the placeholder opens the sentence: Polish presets are lowercase, so "sen: jak było..." was a bug too). `focusAreaPair(..., midSentence:)` for the push example. Chips/list rows keep the label as is. Agreement fixed in 9508788: EN "How {area} showed up this week" and "Check in on {focusAreas} today"; de/es/fr/nb/sv label-first with a colon (pl already was); rule for future copy: a focus-area placeholder never takes a conjugated verb or an article (labels are singular OR plural). Reminders use focusAreaPairInTemplate.
