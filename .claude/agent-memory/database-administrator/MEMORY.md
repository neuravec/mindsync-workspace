## Process & Feedback
- [heroku config redaction gotcha](feedback_heroku_config_redaction.md) — `heroku config` uses `KEY:  value` (colon), not `KEY=value`; an `=`-based sed redact silently fails and leaks secrets — match on `:` or just don't print values
- [heroku run local stdout buffering](feedback_heroku_run_local_stdout_buffering.md) — redirected outfile can sit at 0 bytes for minutes after the dyno already finished; don't double-background (no trailing `&` with run_in_background:true), reconcile with `heroku ps` before assuming a hang/failure
- [Heroku CLI auth blocked](feedback_heroku_cli_auth_blocked.md) - "not logged in"/"Invalid credentials": never inspect credential files (classifier block); check whoami first, ship validated script + pending report, operator runs `heroku login`
- [Dyno script per-query txn](reference_dyno_script_per_query_txn.md) - exec() one-line helper: READ ONLY txn + rollback per query; --no-tty exit 1 is normal; build scripts via Write, not heredoc
- [Offline SQL dry-run via pglast](reference_offline_sql_validation_pglast.md) - fake app.db.session + pglast + SQLAlchemy compile catches syntax, stray :binds and non-REPL-safe lines before a dyno run
